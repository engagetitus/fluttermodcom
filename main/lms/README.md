# lms

A Modcom Institute of Technology Flutter project Course.

## Overview

This is a simple Flutter project for a Learning Management System (LMS) for a college/institution. 

## Flutter Frontend / UI
### 1. Login Screen / Signup
Description: A screen for users to enter their credentials.
| Login                      | SignUp |
|------------------------------|------|
| Username and Password fields | Fname, Lname|
| Login button                 | email |
| Option for password recovery | phone |
||github, profilepic, address|

### 2. Dashboard Screen
Description: A central hub where users can navigate to different sections of the LMS.
#### Features:
Summary of user activities
- Quick links to other screens
### 3. Enter Marks Screen
Description: A screen for instructors to enter student marks.
#### Features:
- Select course
- Select student
- Enter marks
### 4. View Reports Screen
Description: A screen for students and instructors to view academic reports.
#### Features:
- Select report type (e.g., grades, attendance)
- Display report
#### 5. Analysis Screen
Description: A screen to analyze student performance.
#### Features:
- Charts and graphs showing performance metrics
- Filters for specific time periods or courses
#### 6. Fee Statements Screen
Description: A screen for students to view their fee statements.
#### Features:
- List of fee statements
- Payment history
### 7. Register Course Screen
Description: A screen for students to register for courses.
#### Features:
- List of available courses
- Register button
### 8. Attendance Screen
Description: A screen for instructors to mark attendance.
#### Features:
- Select course
- Mark attendance
